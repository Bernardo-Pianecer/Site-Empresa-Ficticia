# 🍫 Mimos da Vovó — Site Institucional Fictício

Site institucional desenvolvido para o Projeto Integrador do curso Técnico
em Desenvolvimento de Sistemas (SENAI), simulando a construção de uma marca
real de brigadeiros artesanais.

## Sobre o projeto

O projeto une tradição familiar, identidade visual e processos de gestão,
marketing e produção. A proposta é demonstrar como uma ideia caseira pode se
tornar um negócio organizado, planejado e capaz de se conectar com as pessoas
de forma afetuosa e estratégica.

## Objetivo

Apresentar de forma estruturada os processos produtivos, organizacionais e
estratégicos da empresa fictícia Mimos da Vovó.

## Tecnologias

- **HTML5** — estrutura semântica
- **CSS3 / Tailwind CSS** — estilização e responsividade
- **JavaScript** — interatividade e manipulação do DOM
- **Google Sheets** — organização dos dados do negócio
- **Miro** — modelagem dos fluxogramas de processo
