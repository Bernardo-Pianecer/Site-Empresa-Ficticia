# Site institucional fictício – Projeto Integrador

Site institucional e técnico desenvolvido para o projeto integrador
do curso, abordando produção, gestão, planejamento e controle de processos
de uma empresa fictícia de brigadeiros artesanais.

## Tecnologias
- HTML5
- Tailwind CSS
- JavaScript
- Google Sheets
- Miro (fluxograma)

## Objetivo
Apresentar de forma estruturada os processos produtivos, organizacionais
e estratégicos da empresa Mimos da Vovó.
